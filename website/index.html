One workspace

Three ways into your data, side by side in tabs.

Notebooks for exploring, files for queries you keep, and a data viewer for the table itself. Open them together and switch with a keystroke.

SQL cells with results right under each one. Ctrl Enter runs a cell, Shift Enter runs it and moves on, and named :parameters get an inline form.

A classic editor for .sql files: table- and column-aware autocomplete, Format SQL, bookmarks, snippets and Explain with Cmd E. Every query lands in History.

Click a table to browse it. Page, filter and edit cells inline: changes wait as staged edits until you Commit or Roll Back.

Dump and restore

Write a PostgreSQL, MySQL, SQLite or DuckDB database to a .sql file, with structure, data and drop per table. A restore checks every statement before anything runs, and MongoDB backs up to one file.

Undo an edit after Commit

Data viewer edits on PostgreSQL, MySQL and SQLite keep a copy of each row. Data Rewind shows the exact SQL that puts them back, and stops if a row changed since.

Get started

Up and running in a minute.

  1. Download

    Get the signed, notarized DMG from the releases page and drag Dblore to Applications. It updates itself.

  2. Connect

    Add a PostgreSQL, MySQL, MariaDB or MongoDB server, open a SQLite file, or install a plugin for more.

  3. Run

    Create a notebook with Cmd T and run a cell with Ctrl Enter. More in the docs.
